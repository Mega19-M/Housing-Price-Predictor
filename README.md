# Housing Price Predictor using Linear Regression

## About the Project
This project is part of my Artificial Intelligence and Machine Learning internship.

The objective is to predict California housing prices using a Linear Regression model.

## Technologies Used
- Python
- Google Colab
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## Machine Learning Workflow
1. Dataset loading
2. Data exploration
3. Data preprocessing
4. Training and testing split (80:20)
5. Linear Regression model training
6. Price prediction
7. Model evaluation using MSE and R² Score
8. Actual vs Predicted visualization

## Dataset
California Housing Dataset from Scikit-learn.
